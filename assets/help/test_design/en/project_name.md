The project name is how you identify this test in the Projects list. It also appears in the banner while you enter group sizes and review results.

Use a short name that says what you are comparing. Add a date, distance, or session name if it helps you distinguish repeat tests.

**Examples**

- **Weaver vs. Isosceles at 25 yd** for a stance comparison.
- **Bench rest setup, June session** for a comparison you plan to repeat.
