When this option is on, Results substitutes the average of all recorded group sizes for each blank group size. That overall average is called the grand mean. Blank cells stay blank in the Data Matrix.

Leave the option off for a complete test. Use it when you need a provisional comparison and a measurement is missing. Substituting the same average can make differences between factor states look smaller. Collect the missing measurements when possible.

**Example**

If the recorded group sizes are **0.20** and **0.40** in the same unit, Results uses **0.30** for a blank cell when this option is on.
